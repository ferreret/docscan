## 2. Fix: warning `QPropertyAnimation` sobre `fixedWidth`

Durante la validación se observó un warning repetido en el log cada vez que se
toggleaba el sidebar colapsable del launcher:

```
QPropertyAnimation: you're trying to animate a non-existing property fixedWidth
```

### Causa raíz

En `app/ui/launcher/sidebar.py::_toggle()` había una línea muerta que creaba
un `QPropertyAnimation` sobre `fixedWidth`, una propiedad no animable de
`QWidget`. Un comentario inmediatamente debajo ya explicaba el problema
(*"fixedWidth no es una propiedad directa, usamos minimumWidth/maximumWidth"*)
y las dos animaciones reales sobre `minimumWidth` y `maximumWidth` estaban
correctamente implementadas — pero el autor original olvidó borrar la línea
rota, que se ejecutaba en cada clic y generaba el warning aunque nunca se
usaba el resultado.

### Solución

Eliminación de la línea obsoleta y reescritura del comentario para que el
*por qué* quede claro a futuros lectores. Cambio mínimo (1 línea neta) y sin
riesgo funcional: las animaciones que sí funcionan no se tocaron. La
verificación post-fix con arranque real confirmó el log completamente limpio
de warnings de `QPropertyAnimation`.

Commit: **`ce512af fix(launcher): eliminar warning QPropertyAnimation sobre fixedWidth`**.

  trivial pero llevaba tiempo ensuciando el log y distrae en futuras
  depuraciones. Fix de 1 minuto que se lleva el ruido de encima.

  `test_launcher.py` falla cuando se ejecuta en isolation (problema de orden

  porque otros tests fuerzan el import correcto. Es un bug preexistente y
  ortogonal al fix de hoy — se documenta aquí para retomarlo en otra sesión.
