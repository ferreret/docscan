---
name: Actualizar docs en cada cambio
description: Tras cada cambio funcional, actualizar README.md y CHANGELOG.md antes de commit
type: feedback
---

Al hacer cambios en el código, actualizar siempre README.md y CHANGELOG.md antes del commit final.

**Why:** El usuario quiere que la documentación pública esté siempre sincronizada con el estado real del proyecto. El README es el escaparate en GitHub y el CHANGELOG el historial para usuarios.

**How to apply:** Antes de hacer commit de cambios funcionales, revisar si afectan a README.md (métricas, features, screenshots) o CHANGELOG.md (nueva entrada o actualización de la sección en curso). Incluir las actualizaciones en el mismo commit o en uno inmediatamente posterior.
