---
name: Push al cerrar sesión
description: Siempre hacer git push al remote antes de cerrar para que el jefe vea el progreso
type: feedback
---

Siempre hacer `git push` al cerrar la sesión para que el jefe pueda revisar los cambios y el informe de progreso.

**Why:** El jefe revisa el repositorio remoto para ver el avance del proyecto.

**How to apply:** Al final de cada sesión, antes de despedirse, verificar que todos los commits están pusheados al remote.
