# :material-keyboard: Atajos de teclado

## Workbench

Los de captura son los de FlexibarNET 10.

| Atajo | Acción |
|-------|--------|
| `F5` | Escanear |
| `Ctrl+I` | Importar ficheros |
| `F9` | Procesar todas las páginas del lote |
| `Ctrl+T` | Transferir lote |
| `Ctrl+W` | Cerrar lote sin transferir |
| `Ctrl+P` | Reprocesar la página actual |
| `←` / `→` | Página anterior / siguiente |
| `Home` / `End` | Primera / última página |
| `Ctrl+→` | Siguiente con barcode |
| `Ctrl+Shift+→` | Siguiente pendiente de revisión |
| `Ctrl+G` | Navegación por script (`on_navigate_script`) |
| `Ctrl+N` / `Insert` | Añadir un código de barras a mano (también `Ctrl+B`) |
| `Supr` / `Retroceso` sobre una fila de barcode | Eliminar ese código |
| `Ctrl+Z` | Deshacer la última edición de códigos |
| `Ctrl+D` | Marcar / desmarcar la página como separador de documento |
| `Alt+↑` / `Alt+↓` | Mover la página una posición arriba / abajo |

!!! tip "Ir a una página concreta"

    El contador `N / M` de la barra bajo el visor es editable: haz clic
    sobre el número, escribe el que quieras y pulsa `Intro`. `Esc` o hacer
    clic fuera cancelan. Mientras escribes ahí, las teclas simples
    (flechas, `Home` / `End` y `Supr`) no actúan como atajos.

## Visor

| Atajo | Acción |
|-------|--------|
| `Ctrl++` (o `Ctrl+=`) / `Ctrl+-` | Zoom in / out |
| Rueda del ratón | Zoom in / out |
| `Ctrl+F` | Ajustar a ventana |
| `Ctrl+0` | Zoom 100% |
| `Ctrl+R` | Rotar 90° a la derecha |
| `Ctrl+M` | Excluir la página / volver a incluirla (una página excluida no se transfiere) |
| `Supr` | Eliminar página |

## Editor de scripts

En los eventos, los pasos Script y el script de nombre.

| Atajo | Acción |
|-------|--------|
| `Tab` | Sangrar (la selección, si hay) |
| `Shift+Tab` | Quitar sangría |
| `Intro` | Nueva línea con la misma sangría (un nivel más tras `:`) |

## AI Mode

| Atajo | Acción |
|-------|--------|
| `Ctrl+Intro` | Enviar el mensaje |
